# Kasir Sembako

Aplikasi kasir untuk toko sembako: penjualan, barang timbangan (telur, beras
curah), pencatatan pengeluaran, dan tutup kasir harian yang dikloping dengan
hitungan fisik uang.

Satu halaman HTML tanpa dependensi. Data penjualan tersimpan di browser
perangkat yang membukanya, bukan di server.

- Cetak struk ke printer thermal Bluetooth lewat Web Bluetooth (Chrome Android).
- Bisa dipasang ke layar utama HP dan tetap terbuka saat internet putus.

Sumbernya dibangkitkan dari `kasir-sembako.html` lewat `build-offline.sh`.
